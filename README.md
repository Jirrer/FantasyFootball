# NFL Playoffs Fantasy Football

## Full-stack web application for a group of users to draft, manage, and compete against each other in the NFL postseason. 

All of the popular Fantasy Football services stop at the postseason.
This project aims to give users the option the continue playing all the way through the superbowl.
Just like regular Fantasy Football, a groul of users complete an NFL draft from teams that have made the postseason (with each player being draftable by up to two players).
Every week before the games begin each user will set their lineup, choosing who to start and who to leave on the bench.
Users are awarded points for their starters performance, as well as additional points if that players team advances.
Users must assemble a starting linup each week with whatever players that are still available (with many spots becoming empty as the postseason progresses).
Finally, whicher user has the most total Fantasy points at the end of the superbowl is the winner of the group.
