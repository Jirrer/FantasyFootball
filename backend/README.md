# Fantasy Football Backend

## Flask RESTful API built to handle client reqquest, along with a Python backend that manages data logic. 

Built with a Python file 'app.py' that handles different RESTful APIs (a specific API is used for the draft etc.).
Python backend that is used to update player information and handling Fantasy Football point logic.

## Installation
*  Clone git repository
*  Create SQLite database using schema.sql
*  Navigate to the Backend directory
*  Create Python venv and pip install requirements.txt
*  Add a .env file with a variable pointing to that database
*  Run "Python app.py"
